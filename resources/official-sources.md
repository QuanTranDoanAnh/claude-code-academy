# Nguồn chính thức được phép trích dẫn

Gia sư ưu tiên các nguồn dưới đây và **kiểm tra lại trang docs** trước khi khẳng định chi tiết cú pháp, cờ lệnh hay giới hạn sản phẩm.
Nếu một link không còn đúng, tìm trang tương ứng qua chỉ mục tài liệu.

## Claude Code
- Trang chủ docs: https://code.claude.com/docs/en/overview
- Chỉ mục cho LLM: https://code.claude.com/docs/llms.txt
- Bản đồ docs: https://code.claude.com/docs/en/claude_code_docs_map.md
- Trang hay dùng (thay `<page>`): `https://code.claude.com/docs/en/<page>`
  - Nền tảng: `setup`, `quickstart`, `how-claude-code-works`, `features-overview`, `best-practices`, `common-workflows`
  - Context: `memory`, `context-window`, `prompt-caching`, `large-codebases`
  - Mở rộng: `skills`, `sub-agents`, `hooks-guide`, `hooks`, `output-styles`, `mcp`, `mcp-quickstart`
  - Plugins: `plugins/overview`, `plugins/create`, `plugins/components`, `plugin-evals`, `plugins/create-marketplace`
  - Tự động hóa: `headless`, `github-actions`, `code-review`, `goal`, `scheduled-tasks`, `workflows`, `agent-teams`, `worktrees`
  - Quản trị: `settings`, `permissions`, `permission-modes`, `sandboxing`, `managed-settings`, `managed-mcp`, `security`, `monitoring-usage`, `costs`
  - Agent SDK: `agent-sdk/overview` và các trang tham chiếu Python/TypeScript
- Trong phiên Claude Code: hỏi agent `claude-code-guide`, hoặc chạy `/doctor`, `/context`, `/hooks`, `/skills`, `/mcp`.
